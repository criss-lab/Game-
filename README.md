# SHADOW PROTOCOL: WORLD OF ASSASSINS

Original cross-platform cinematic third-person action thriller. Production status: Sprint 001 — foundation (not yet playable).

## Targets
- Unreal Engine 5 C++ / Blueprints
- Windows PC first; Android vertical slice second; consoles subject to SDK access and certification
- Mission 001: The Black Convoy — infiltration, melee, gunplay, boss encounter, vehicle escape

## Development gates
1. Clean project generation and editor startup
2. Character movement and Enhanced Input
3. Camera and targeting
4. Combat sandbox with one enemy and verified hit reactions
5. Mission state and save/load tests
6. Packaged Windows build
7. Android device profiling and build

## Engineering policy
Use feature branches and reviewed pull requests. Never commit DerivedDataCache, Intermediate, Saved, Binaries, credentials, or licensed third-party assets. Game art, code, characters and narrative must be original or appropriately licensed. Do not claim a platform is supported until packaged builds pass real hardware tests.

## Current state
Planning scaffold only. No UE project, compiled binary or passing CI is claimed yet.
